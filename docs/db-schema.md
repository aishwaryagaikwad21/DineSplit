# DineSplit Database Schema

## 1. Restaurant

### Fields
- _id
    - Data type: ObjectID
    - Required: true
    - unique: true
    - Default: Auto-generated by MongoDB
- name
    - type: String
    - required: true
    - Unique: false
    - validation: non-empty string
- address
    - type: String
    - required: true
    - validation: non-empty string
- email
    - type: String
    - required: true
    - unique: true
    - validation: npm validator
- password
    - type: String
    - Required: true
    - Unique: false
    - validation: strong password
- socialMediaHandles
    - type: Map, 
    - of: String
    - Required: false
- menu_file
    - type: String
    - Required: true
    - Unique: false
    - Validation: valid file path, json
    - Reference/File: Reference to uploaded JSON menu --> instance method to upload a file

## 2. Order

### Fields

- order_id
    - Data type: ObjectID
    - Required: true
    - unique: true
    - Default: Auto-generated by MongoDB
    - Reference/File: Primary identifier
- restaurant_id
    - type: ObjectID
    - Required: true
    - validation: valid ObjectID
    - Reference/File: References Restaurant (FK)
- table_number
    - type: Number
    - required: true
    - validation: positive integer
- items
    - type: Array of objects [{ }]
    - required: true
    - validation: must contain at least 1 item
    - Reference/File: Restaurant's menu file / embedded data
    - Description: Stores the dish name, price at the time
      of ordering, and quantity

### items[{ }]
- dish_name
    - type: String
    - required: true
    - validation: non-empty string
- price
    - type: Number
    - required: true
    - validation: must be greater than 0
- quantity
    - type: Number
    - required: true
    - Validation: Positive integer

## 3. Bill
### Fields
- bill_id
    - type: ObjectID
    - required: true
    - unique: true
    - validation: valid bill format
    - Reference/File: Primary identifier
- order_id
    - type: ObjectID
    - Required: true
    - Unique: true
    - Validation: valid order reference
    - Reference/File: References Order
- total_amount
    - type: Number
    - required: true
    - Unique: false
    - Validation: valid positive number
    - Reference/File: References Order items
- status
    - type: Boolean
    - required: true
    - validation: enum ["unpaid", "paid"]
    - default: "unpaid"
- createdAt
    - type: Date
    - required: true

## 4. Split Bill
- group_id
    - type: ObjectID
    - required: true
    - unique: true
    - Reference: primary identifier
- bill_id
    - type: ObjectID
    - required: true
    - unique: true
    - reference/file: references bill
- split_type
    - type: String
    - validation: enum ["equal", "item-wise"]
- separate_bill
    - Type: Array of objects
    - required: true
    - validation: must contain at least 2 members
    - reference/ File: embedded data

### separate_bill[ ]
- member_name
    - Type: String
    - Required: true
    - Validation: non-empty string
- amount_to_pay
    - type: Number
    - required: true
